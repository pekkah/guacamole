# Generated Code Reference: ComputingContext

This document describes the code generated by the ComputingContext source generator for classes marked with `[ComputingContext]` attribute.

## Overview

The source generator analyzes your context class and automatically generates:
- Strongly-typed change records
- Mutation methods (Add/Remove/Replace/Set)
- Change tracking infrastructure
- Computation nodes for graph integration
- SaveChanges/DiscardChanges methods
- Property implementations

## Example User Code

```csharp
using Guacamole;
using Guacamole.Core.Providers;

[ComputingContext]
public partial class CompilerContext : ComputingContextBase
{
    // Input source (get-only) - generates mutation methods (auto-managed)
    public partial IncrementalValuesProvider<SourceFile> SourceFiles { get; }

    // Derived computation (has setter) - no mutation methods (user-managed)
    public partial IncrementalValuesProvider<SyntaxTree> ParsedTrees { get; set; }

    public CompilerContext(IServiceProvider services) : base()
    {
        InitializeComputationNodes();

        // Configure derived computations
        ParsedTrees = SourceFiles.Select(file => Parse(file));
    }

    partial void InitializeComputationNodes();
}
```

## Generated Code Structure

### 1. Change Record Types

For each **get-only property** (auto-managed), strongly-typed change records are generated:

```csharp
// For collection properties (IncrementalValuesProvider<T>)
public abstract record SourceFileChange(SourceFile Item, DateTimeOffset Timestamp)
{
    public sealed record Add(SourceFile Item, DateTimeOffset Timestamp)
        : SourceFileChange(Item, Timestamp);

    public sealed record Remove(SourceFile Item, DateTimeOffset Timestamp)
        : SourceFileChange(Item, Timestamp);

    public sealed record Replace(SourceFile OldItem, SourceFile NewItem, DateTimeOffset Timestamp)
        : SourceFileChange(NewItem, Timestamp)
    {
        public SourceFile OldItem { get; } = OldItem;
    }
}

// For single-value properties (IncrementalValueProvider<T>)
public abstract record ProjectChange(DateTimeOffset Timestamp)
{
    public sealed record Set(Project Value, DateTimeOffset Timestamp)
        : ProjectChange(Timestamp)
    {
        public Project Value { get; } = Value;
    }
}
```

**Zero Boxing:** All types are strongly-typed to the actual property types - no object boxing occurs.

### 2. Change Tracking Fields

```csharp
// For each property
private readonly List<SourceFileChange> _SourceFilesChanges = new();
private readonly HashSet<SourceFile> _currentSourceFiles = new();
```

### 3. Computation Node Classes

```csharp
private sealed class SourceFilesNode : CollectionComputationNodeBase<SourceFile>
{
    private readonly CompilerContext _context;

    public SourceFilesNode(CompilerContext context)
        : base($"CompilerContext.SourceFiles")
    {
        _context = context;
    }

    public override Result<IEnumerable<SourceFile>, ComputationError> Compute(
        ComputationContext context)
    {
        return Result<IEnumerable<SourceFile>, ComputationError>
            .Success(_context._currentSourceFiles);
    }
}
```

#### Collection Properties

public void AddSourceFile(SourceFile item)
{
    ThrowIfDisposed();
    ArgumentNullException.ThrowIfNull(item);

    try

        if (_currentSourceFiles.Contains(item))

            throw ContextOperationException.DuplicateItem("SourceFiles", item);

    }
    finally
    {
        Lock.ExitWriteLock();
    }
}

### 5. SaveChanges Methods

```csharp
public bool HasPendingChanges => _SourceFilesChanges.Count > 0 || _ProjectChanges.Count > 0;

public void SaveChanges()
{
    ThrowIfDisposed();

    Lock.EnterWriteLock();
    try
    {
        // Apply SourceFiles changes
        foreach (var change in _SourceFilesChanges)
        {
            switch (change)
            {
                case SourceFileChange.Add add:
                    _currentSourceFiles.Add(add.Item);
                    break;
                case SourceFileChange.Remove remove:
                    _currentSourceFiles.Remove(remove.Item);
                    break;
                case SourceFileChange.Replace replace:
                    _currentSourceFiles.Remove(replace.OldItem);
                    _currentSourceFiles.Add(replace.Item);
                    break;
            }
        }

        // Apply Project changes (last one wins for single-value)
        if (_ProjectChanges.Count > 0)
        {
            var lastChange = _ProjectChanges[_ProjectChanges.Count - 1];
            if (lastChange is ProjectChange.Set set)
            {
                _currentProject = set.Value;
            }
        }

        // Clear all change lists
        _SourceFilesChanges.Clear();
        _ProjectChanges.Clear();
    }
    finally
    {
        Lock.ExitWriteLock();
    }
}

public Task SaveChangesAsync(CancellationToken cancellationToken = default)
{
    SaveChanges();
    return Task.CompletedTask;
}

public void DiscardChanges()
{
    ThrowIfDisposed();

    Lock.EnterWriteLock();
    try
    {
        _SourceFilesChanges.Clear();
        _ProjectChanges.Clear();
    }
    finally
    {
        Lock.ExitWriteLock();
    }
}
```

### 6. Property Implementations

For **get-only properties** (auto-managed):

```csharp
private IncrementalValuesProvider<SourceFile> _SourceFilesProvider;

public partial IncrementalValuesProvider<SourceFile> SourceFiles
{
    get
    {
        if (_SourceFilesProvider.Node == null)
        {
            _SourceFilesProvider = new IncrementalValuesProvider<SourceFile>(
                _SourceFilesNode,
                Graph,
                new ProviderMetadata(TrackingName: "SourceFiles"));
        }
        return _SourceFilesProvider;
    }
}
```

For **properties with setters** (user-managed), no implementation is generated - you provide the backing field and logic yourself.

### 7. Node Registration

```csharp
partial void InitializeNodes()
{
    _SourceFilesNode = new SourceFilesNode(this);
    Graph = Graph.AddNode(_SourceFilesNode);

    _ProjectNode = new ProjectNode(this);
    Graph = Graph.AddNode(_ProjectNode);
}
```

## Performance Characteristics

### Zero Boxing
- All change records use concrete types (SourceFile, not object)
- No interface overhead for change tracking
- JIT can optimize switch expressions on sealed record types

### Memory Efficiency
- Separate typed lists prevent object[] allocations
- HashSet<T> for O(1) duplicate detection
- Change lists cleared after commit

### Thread Safety
- ReaderWriterLockSlim allows concurrent reads
- Single writer exclusivity for mutations
- Lock-free for read-only property access

### Incremental Computation
- O(changes) complexity in SaveChanges
- Only modified properties trigger recomputation
- Graph invalidation handled automatically

## Debugging Generated Code

To view generated code:
1. Add `<EmitCompilerGeneratedFiles>true</EmitCompilerGeneratedFiles>` to your .csproj
2. Build project
3. Check `obj/Debug/net10.0/generated/` directory
4. Look for `YourContext.g.cs` file

## Common Patterns

### Batch Operations with Error Handling

```csharp
try
{
    context.AddSourceFiles(newFiles);
    await context.SaveChangesAsync();
}
catch (ContextOperationException ex)
{
    Console.WriteLine($"Operation {ex.OperationType} failed at index {ex.OperationIndex}");
    Console.WriteLine($"Failed item: {ex.FailedItem}");
}
```

### Incremental Updates

```csharp
// Replace one file - only that file and dependents recompute
context.ReplaceSourceFile(oldFile, newFile);
await context.SaveChangesAsync();
```

### Change Inspection

```csharp
if (context.HasPendingChanges)
{
    await context.SaveChangesAsync();
}
else
{
    context.DiscardChanges(); // Clear tracking if needed
}
```
