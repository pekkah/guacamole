# Generated Code Reference: ComputingContext

This document describes what the `Guacamole.SourceGenerators` package generates for classes marked with `[ComputingContext]`, and the diagnostics it reports. The examples below match the generator's snapshot tests in [`tests/Guacamole.SourceGenerators.Tests/Snapshots`](../tests/Guacamole.SourceGenerators.Tests/Snapshots/).

## Overview

For each `[ComputingContext]` class the generator emits one file containing:

- a private source field per input property (`IIncrementalSource<T>` or `IIncrementalValueSource<T>`)
- the context's **public parameterless constructor**, which creates each source with the protected `ComputingContextBase.CreateSource<T>` / `CreateValueSource<T>` helpers; they register the source's node in the context's graph and subscribe the context to its changes
- the implementation of each input property, returning the source's provider
- a `{Property}Source` accessor per input property for pushing data

Nothing else is generated: there are no mutation methods, change records or `SaveChanges`. Data is pushed through the source accessors (see [Quickstart: Pushing Changes](quickstart.md#pushing-changes)).

## Property Classification

Only instance properties typed `IncrementalValueProvider<T>` or `IncrementalValuesProvider<T>` are considered.

| Declaration | Classification |
|-------------|----------------|
| `partial` and get-only | **Input**: implemented by the generator |
| not `partial`, has a setter (any accessibility) | **User-managed**: ignored by the generator; you assign it |
| `partial` with a setter | Error **GUAC0005** |
| not `partial`, get-only (including expression-bodied) | Error **GUAC0003** |

A partial property whose implementation part you wrote yourself is left alone.

## Example User Code

```csharp
using Guacamole;

namespace Test
{
    [ComputingContext]
    public partial class TestContext : ComputingContextBase
    {
        public partial IncrementalValuesProvider<string> Items { get; }
        public partial IncrementalValueProvider<int> Count { get; }
    }
}
```

## Generated Code

```csharp
// <auto-generated/>
// Generated by Guacamole Source Generator
// This file contains push-based reactive source properties
#nullable enable

namespace Test
{
    partial class TestContext
    {
        private global::Guacamole.IIncrementalSource<string>? _ItemsSource;
        private global::Guacamole.IIncrementalValueSource<int>? _CountSource;

        /// <summary>
        /// Initializes the computing context and its sources.
        /// </summary>
        public TestContext() : base()
        {
            _ItemsSource = CreateSource<string>("TestContext.Items");
            _CountSource = CreateValueSource<int>("TestContext.Count");
        }

        public partial global::Guacamole.IncrementalValuesProvider<string> Items
        {
            get
            {
                if (_ItemsSource == null)
                    throw new global::System.InvalidOperationException("Property Items has not been initialized. This is a framework bug.");

                return _ItemsSource.AsProvider();
            }
        }

        public global::Guacamole.IIncrementalSource<string> ItemsSource
        {
            get { /* same null guard */ return _ItemsSource; }
        }

        public partial global::Guacamole.IncrementalValueProvider<int> Count
        {
            get { /* same null guard */ return _CountSource.AsProvider(); }
        }

        public global::Guacamole.IIncrementalValueSource<int> CountSource
        {
            get { /* same null guard */ return _CountSource; }
        }
    }
}
```

(XML doc comments on the properties are omitted above; the full output is in the snapshot `_.Generator_WithMultipleProperties_GeneratesAllSources#Test.TestContext.g.verified.cs`.)

Notes:

- **Fully qualified names**: every type in generated code is written with `global::`, because the generated file has no `using` directives. Item types from other namespaces, nullable annotations and generic arguments are preserved.
- **Accessibility**: each input property keeps its declared accessibility (`internal`, `protected internal`, `private`, ...). The `{Property}Source` accessor uses the same accessibility.
- **Constructor**: the generated parameterless constructor is always `public` and is emitted even for a context with no input properties. Declaring your own parameterless constructor reports **GUAC0008** (the generator then omits its constructor). Declare constructors with parameters that chain to `: this()`; a constructor that never reaches `: this()` (via `: base(...)`, no initializer, or a `: this(...)` chain that doesn't end in `: this()`) reports **GUAC0009**.
- **Source IDs** are `"{ClassName}.{PropertyName}"` and are scoped to the context's own graph.

### Nested and Generic Contexts

Contexts can be nested in other types and can be generic. The generator re-emits each containing type as a `partial` declaration with its type parameters and kind (`class`, `struct`, `record`, `record struct`, `interface`):

```csharp
namespace Test
{
    partial class Outer<T>
    {
        partial record Middle
        {
            partial class NestedContext
            {
                private global::Guacamole.IIncrementalSource<T>? _ItemsSource;
                // ...
            }
        }
    }
}
```

A context in the global namespace is emitted without a `namespace` declaration.

### Hint Names

Each generated file has a hint name that is unique per type: namespace, containing types joined with `+`, and metadata names including generic arity, e.g. `Test.Outer`1+Middle+NestedContext.g.cs`. Two contexts with the same name in different namespaces or containing types therefore do not collide.

## Diagnostics

The package contains a source generator and an analyzer. The generator reports the errors that decide whether code can be generated (GUAC0003, GUAC0005-GUAC0008). The analyzer (`ComputingContextAnalyzer`) reports the warnings you may want to suppress (GUAC0004, GUAC0009): Roslyn does not apply `#pragma warning disable` or `[SuppressMessage]` to diagnostics reported by a source generator, so these are analyzer diagnostics and support every suppression mechanism. No diagnostic is reported by both.

| ID | Severity | Category | Reported when |
|----|----------|----------|---------------|
| GUAC0003 | Error | Guacamole.SourceGenerator | A get-only provider property is not `partial`. Make it `partial` (input) or add a setter (user-managed). |
| GUAC0004 | Warning | Guacamole.Performance | A provider property's item type does not have value equality (not a record, does not implement `IEquatable<T>`, not a primitive, `string` or enum; type parameters are not checked). Applies to input and user-managed properties. `ImmutableDictionary<TKey, TValue>` and `ImmutableSortedDictionary<TKey, TValue>` (including what `CollectToDictionary` returns) are compared entry by entry by the runtime, in O(N) when a stage recomputes, so they are reported only when `TValue` lacks value equality (checked recursively for nested dictionaries), and the message names that value type. Every recomputation will look like a change. |
| GUAC0005 | Error | Guacamole.SourceGenerator | A `partial` provider property has a setter. User-managed properties must not be `partial`. |
| GUAC0006 | Error | Guacamole.SourceGenerator | The context class, or a type that contains it, is not `partial`. No code is generated. |
| GUAC0007 | Error | Guacamole.SourceGenerator | A class marked `[ComputingContext]` does not derive from `Guacamole.ComputingContextBase`. No code is generated. |
| GUAC0008 | Error | Guacamole.SourceGenerator | The context declares its own parameterless constructor, which would collide with the generated one. The generator omits its constructor; move the code into a constructor with parameters chaining to `: this()`. |
| GUAC0009 | Warning | Guacamole.SourceGenerator | An instance constructor never reaches `: this()`, so the generated sources stay uninitialized. `: this(...)` chains are followed. |

### Suppressing a Warning

The analyzer warnings can be suppressed like any other warning. For example, for a provider whose values are deliberately compared by identity (a value without value equality that is recomputed only when its inputs change, and where a recomputation should always count as a change):

```csharp
[ComputingContext]
public partial class CompilerContext : ComputingContextBase
{
#pragma warning disable GUAC0004 // GlobalImplContext is compared by identity on purpose
    public IncrementalValueProvider<GlobalImplContext> GlobalImplContextProvider { get; set; }
#pragma warning restore GUAC0004

    // or, for one member (or on the class, for all of them):
    [SuppressMessage("Guacamole", "GUAC0004", Justification = "Compared by identity on purpose")]
    public IncrementalValueProvider<Scope> RootScope { get; set; }
}
```

or for a whole project or folder in `.editorconfig`:

```ini
[*.cs]
dotnet_diagnostic.GUAC0004.severity = none   # or suggestion, warning, error
```

Before suppressing GUAC0004, consider the cost: every recomputation of such a provider counts as a change, so everything downstream of it recomputes too and its output handlers fire. An alternative is to pass a comparer to the operator that produces the value.

GUAC0001 and GUAC0002 were removed before the first release (they could never be reported) and their IDs are retired. The rule list is tracked in [`AnalyzerReleases.Unshipped.md`](../src/Guacamole.SourceGenerators/AnalyzerReleases.Unshipped.md).

## How the Generator Works

The generator is an `IIncrementalGenerator` that finds contexts with `ForAttributeWithMetadataName("Guacamole.ComputingContextAttribute")`. All semantic analysis happens in that step and produces an equatable model (no symbols or syntax nodes), so Roslyn can cache the pipeline and skip regeneration when a context's shape has not changed. Source output and diagnostics are produced by two separate branches of that result, so for example a diagnostic location shift does not force the source to be re-emitted. The analyzer warnings are computed by the separate `ComputingContextAnalyzer`, outside the generator pipeline.

## Viewing Generated Code

1. Add `<EmitCompilerGeneratedFiles>true</EmitCompilerGeneratedFiles>` to your project file
2. Build the project
3. Look in `obj/<Configuration>/net11.0/generated/Guacamole.SourceGenerators/Guacamole.SourceGenerators.ComputingContextGenerator/`

In an IDE you can also expand Dependencies > Analyzers > Guacamole.SourceGenerators.
